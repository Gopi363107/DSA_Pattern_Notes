#  Data Structures and Their Purpose (MNC Interview Focus)

This document lists only the essential data structures and why they are used in coding interviews.

---

#  1. Array
**Purpose:**
- Store elements in contiguous memory
- Fast access using index (O(1))
- Used for basic processing and iteration problems

---

#  2. String
**Purpose:**
- Store and manipulate sequences of characters
- Used in pattern matching and text-based problems

---

# 🧾 3. HashMap / HashSet
**Purpose:**
- Store key-value pairs or unique elements
- Fast lookup, insert, delete (O(1) average)
- Used for frequency counting and fast searching

---

#  4. Stack
**Purpose:**
- LIFO (Last In First Out) structure
- Used for recursion simulation, backtracking, and expression problems

---

#  5. Queue
**Purpose:**
- FIFO (First In First Out) structure
- Used for level-order processing and BFS traversal

---

#  6. Deque
**Purpose:**
- Insert/delete from both ends
- Used in sliding window optimization problems

---

#  7. Tree
**Purpose:**
- Hierarchical data structure
- Used to represent parent-child relationships
- Helps in recursion and searching structured data

---

#  8. Graph
**Purpose:**
- Represents connected data using nodes and edges
- Used for networks, relationships, and path problems

---

#  9. Heap (Priority Queue)
**Purpose:**
- Always provides access to min/max element quickly
- Used for scheduling and top K problems

---

#  10. Linked List
**Purpose:**
- Linear structure with dynamic memory allocation
- Efficient insertion and deletion

---

#  11. Prefix Sum Array
**Purpose:**
- Precompute cumulative sums
- Used for fast range sum queries

---

#  12. Binary Search Tree (BST)
**Purpose:**
- Ordered tree structure
- Used for fast search, insert, delete operations

---

#  13. Trie
**Purpose:**
- Prefix-based tree structure
- Used for fast string search and autocomplete systems

---

#  Final Note
Focus on understanding:
- What each DS stores
- Why it is used
- What problem it solves efficiently
